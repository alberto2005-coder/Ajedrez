## 📝 Descripción

Este juego de ajedrez ofrece:

- Tablero marrón y blanco, sin textura de madera.
- Animaciones suaves de movimiento de piezas.
- Resaltado de movimientos y capturas.
- Vista desde perspectiva blanca o negra.
- Barra lateral para controles del juego.

Se ejecuta directamente desde el navegador o como aplicación de escritorio sin instalaciones complejas.

## 💻 Requisitos

- Sistema operativo: Windows, macOS o Linux.

- Para versión de escritorio: JDK 17+ (si es Java) o ejecutable incluido.

## 🎮 Cómo Jugar

1. Abrir `index.html` en un navegador compatible o ejecutar la aplicación incluida.
2. Seleccionar la perspectiva de las piezas desde la barra lateral.
3. Hacer clic en una pieza para ver movimientos posibles.
4. Mover piezas haciendo clic en la casilla destino.
5. Capturas y movimientos se resaltan automáticamente.

---

## ⌨️ Controles

- **Clic en pieza:** seleccionar para ver movimientos posibles.  
- **Clic en casilla válida:** mover pieza seleccionada.  
- **Barra lateral:** cambiar perspectiva, reiniciar partida, mostrar u ocultar movimientos.

# English Version

A modern chess game for the web, built with **HTML, CSS and JavaScript**. Interactive UI, smooth animations and a rotatable board perspective.

**Play it live:** https://alberto2005-coder.github.io/Ajedrez/

## Description

This chess game provides:

* Brown and white board with no wood texture.
* Smooth piece-move animations.
* Move and capture highlighting.
* White or black board perspective.
* Side bar with game controls.

It runs directly from the browser or as a desktop app with no complex setup.

## Requirements

* Operating system: Windows, macOS or Linux.
* Modern browser (Chrome, Edge, Firefox, Safari) for the web version.
* For the desktop version: JDK 17+ (if Java) or the included executable.

## How to Play

1. Open `index.html` in a compatible browser, or run the included application.
2. Select the piece perspective from the side bar.
3. Click a piece to see its possible moves.
4. Move by clicking the destination square.
5. Captures and moves are highlighted automatically.

## Controls

| Control | Action |
|---|---|
| Click on a piece | Select it to see possible moves |
| Click on a valid square | Move the selected piece |
| Side bar | Change perspective, restart, show/hide moves |
